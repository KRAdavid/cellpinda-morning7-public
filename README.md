# CELLPINDA MORNING 7 공개 제품 공동개발 브리프

이 저장소는 브랜드와 제조사가 같은 화면에서 제품의 존재 이유, 개발 목표, 검증이 필요한 항목, 다음 협업 행동을 확인하는 공개용 정적 브리프입니다.

## 핵심 컨셉

식사를 거르기 쉬운 현대인을 위해 한국인이 익숙한 죽에 필요한 영양을 다시 설계하고, 셀핀다의 발효과학을 더해 언제 어디서나 바로 먹는 휴대형 한 끼 대안을 개발합니다.

소비자용 문장: **좋아하는 죽에 필요한 영양을 더해, 언제 어디서나 바로 먹는 한 끼.**

## 공개 페이지

- `index.html` — Meal Gap부터 제조사 응답과 다음 게이트까지 읽는 메인 브리프
- `gate1-market.html` — 80 SKU 관찰 표본, 후보 선정 기준, 시장 자료의 한계

## 데이터 기준

- `data/product-brief.json` — 컨셉·세 가지 맛·영양 목표·과학 레이어·제조사 질문·개발 상태의 기준 데이터
- `data/market-data.json` — 시장 후보와 비교 대안의 공개 관찰 표본
- `data/PUBLIC_STATUS_SNAPSHOT_20260910.json` — 공개 진행 상태와 다음 게이트
- `data/product-brief.json`의 `evidence.sources` — 공식 영양·표시·식품안전 기준과 사람 대상 GABA 연구를 연구 유형·관찰 범위·사이트 사용 범위로 구분한 근거 레지스트리

페이지는 같은 JSON을 읽어 제품·영양·과학·역할·질문·게이트·근거 레지스트리를 표시합니다. 수치는 R&amp;D Target 또는 공개 관찰 표본으로 구분하며, 제조시험 전 확정값으로 표현하지 않습니다. 원료 연구는 셀핀다 완제품의 효능·권장량·소비기한을 대신하지 않습니다.

## 배포

정적 파일 전체를 GitHub Pages 루트에 배포합니다. 별도 서버나 환경변수는 필요하지 않습니다. `.github/workflows/pages.yml`은 `main`에 push되면 GitHub Pages를 배포합니다.

공개 범위에는 내부 회의 원문, 개인정보, 원가 산식, 배합·함량 확정표, 제조사별 견적, API 키를 포함하지 않습니다.
