# CELLPINDA MORNING 7 공개 배포본

이 폴더는 외부 공개용 정적 웹사이트입니다.

## 포함 범위

- 제품 컨셉
- DAILY 중심 제품 구조
- LIGHT·FULL 확장 방향
- 제품화 Gate
- GATE 1 소비자 검증 기준
- 시장 레퍼런스 요약
- 공급사 서면 협업 방식

## 제외 범위

- 내부 회의·브레인스토밍
- 소비자 원자료와 개인정보
- 원가 산식과 내부 마진
- CP-MATRIX 조성·함량
- 제조사별 제안과 견적
- OpenAI API 키와 AI 분석 endpoint

## 배포

`public` 폴더 전체를 정적 호스팅 서비스의 사이트 루트에 업로드하면 됩니다. 별도 서버나 환경변수가 필요하지 않습니다.
