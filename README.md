# CELLPINDA MORNING 7 공개 Product Development Brief

제조사가 공개페이지를 읽고 제품의 개발 의도와 제안해야 할 제조 변수를 이해할 수 있도록 구성한 정적 브리프입니다.

## 공개 흐름

`Meal Gap → 죽의 친숙성 → 시장 근거 → 기본 죽 3종 → 영양 설계 → 셀핀다 발효과학 → 바로 섭취 경험 → 제조 협업 → 다음 Gate`

## 제품 컨셉

식사를 거르기 쉬운 현대인을 위해, 한국인이 익숙하게 먹어온 죽에 필요한 영양을 다시 설계하고 셀핀다의 발효과학을 더해 언제 어디서나 바로 먹는 휴대형 한 끼 대안입니다.

## 개발 후보

- 단호박죽
- 닭·야채죽
- 쇠고기·버섯죽

영양 후보는 프로틴, 식이섬유, 아연, 셀레늄, 발효 GABA, 아르기닌, 오르니틴이며 원료 가능성·표시 범위·함량·관능·공정·원가는 제조시험 후 확정합니다.

## 자료의 경계

공개 리뷰·노출·가격 신호는 실제 판매량·매출·재구매율과 동일하지 않습니다. `data/gate1-market.json`과 `gate1-market.html`은 시장 방향성, 후보 선정, 제조시험 우선순위를 위한 근거로 사용합니다.

## 배포

정적 GitHub Pages 배포 구조를 유지합니다. `index.html`은 공개 브리프, `gate1-market.html`은 GATE 1 시장 근거 상세 페이지입니다.
